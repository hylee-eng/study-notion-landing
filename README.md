# 스터디 노션

노션을 어려워하는 초심자를 위한 학습 가이드 사이트입니다.

## 파일 구조

- `index.html` - 페이지 마크업. 네비, Hero, 문제 제기, 학습 경로, DB 체험, CTA, 푸터로 구성됩니다.
- `style.css` - 커스텀 CSS 전부. 한글 줄바꿈 전역 설정, 타이포 스케일, 디자인 토큰 기반 컴포넌트 스타일이 들어 있습니다.
- `script.js` - DB 체험 위젯 로직. 업무 데이터 배열과 세 개의 렌더링 함수, 탭 전환 처리를 담당합니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치 과정은 없습니다.

## 사용한 외부 리소스

- Tailwind CSS (CDN)
- Pretendard Variable (CDN) - 한글 웹폰트

두 리소스 모두 CDN으로 불러오므로 인터넷 연결이 필요합니다.

## 핵심 구현 포인트

DB 체험 위젯은 하나의 데이터 배열과 세 개의 렌더링 함수로 구성됩니다.
탭을 전환해도 원본 데이터는 변하지 않고 표현 방식만 달라집니다.
노션 데이터베이스의 "하나의 데이터, 여러 개의 뷰" 개념을 코드 구조 자체로 구현한 부분입니다.
