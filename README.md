# 스터디 노션

노션을 어려워하는 초심자를 위한 학습 가이드 사이트입니다.

## 파일 구조

- `index.html` - 랜딩 페이지. 네비, Hero, 문제 제기, 학습 방식, 학습 경로, DB 체험, 이런 분께 맞습니다, 자주 묻는 질문, CTA, 푸터로 구성됩니다.
- `level-1.html` ~ `level-5.html` - 레벨별 상세 학습 페이지. 다섯 개 모두 같은 구조를 씁니다.
- `style.css` - 커스텀 CSS 전부. 한글 줄바꿈 전역 설정, 타이포 스케일, 디자인 토큰 기반 컴포넌트 스타일이 들어 있습니다.
- `script.js` - 랜딩의 DB 체험 위젯 로직. 업무 데이터 배열과 세 개의 렌더링 함수, 탭 전환 처리를 담당합니다.

## 레벨 페이지 구성

다섯 페이지 모두 아래 순서를 공유합니다.

1. 레벨 머리 - 경로 표시, 제목, 소요 시간, 진행 막대
2. 이 단계를 마치면 - 학습 목표 3개
3. 따라 해봅니다 - 실습 단계 4~6개
4. 여기서 자주 막힙니다 - 초심자가 멈추는 지점 3개
5. 다 했는지 확인하기 - 완료 체크 목록
6. 이전 · 다음 단계 이동

| 파일 | 레벨 | 주제 | 소요 |
|---|---|---|---|
| `level-1.html` | 1 | 손이 먼저 익숙해지기 (슬래시·블록·단축 입력) | 15분 |
| `level-2.html` | 2 | 백지에서 시작하지 않기 (무엇부터 옮길지) | 15분 |
| `level-3.html` | 3 | 데이터베이스라는 발상 (속성·보기·필터) | 20분 |
| `level-4.html` | 4 | 팀과 함께 쓰기 (권한·댓글·웹 게시) | 15분 |
| `level-5.html` | 5 | 내 업무에 맞게 설계하기 (관계형·롤업·템플릿) | 20분 |

## 공통 영역 수정 시 주의

head, 상단 네비, 푸터는 여섯 개 HTML 파일에 각각 복제되어 있습니다.
빌드 과정을 두지 않는 대신 생긴 구조이므로, 네비나 푸터를 고칠 때는
`index.html`과 `level-1~5.html`을 함께 고쳐야 합니다.

## 섹션 여백 규칙

각 섹션의 상하 여백(96px)은 `sec` 클래스가 만듭니다.
"이 단계를 마치면"처럼 `sec`가 없는 섹션은 바로 앞 섹션의 아래 여백에 기대고 있으므로,
**여백 없는 섹션 두 개가 연달아 오면 간격이 0이 됩니다.**
섹션을 새로 끼워 넣을 때는 앞뒤 섹션 중 한쪽에 `sec`가 있는지 확인하세요.

현재 `sec`가 없는 섹션은 레벨 3의 "핵심 개념", 레벨 5의 "상자와 물건 비유" 둘뿐입니다.

## 화면 재현과 해설

레벨 페이지의 노션 화면은 이미지가 아니라 CSS로 그린 재현입니다(`.ui` 계열).
화면에 붙는 설명은 `<figure class="shot">` 안의 `<figcaption class="shot-cap">`으로,
화면 박스 바깥에 세로선과 함께 놓입니다.
학습자가 해설을 노션 화면의 일부로 오인하지 않도록 분리한 구조이므로,
설명을 `.ui` 박스 안에 넣지 마세요.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치 과정은 없습니다.

## 사용한 외부 리소스

- Tailwind CSS (CDN)
- Pretendard Variable (CDN) - 한글 웹폰트

두 리소스 모두 CDN으로 불러오므로 인터넷 연결이 필요합니다.

## 핵심 구현 포인트

DB 체험 위젯은 하나의 데이터 배열과 세 개의 렌더링 함수로 구성됩니다.
탭을 전환해도 원본 데이터는 변하지 않고 표현 방식만 달라집니다.
노션 데이터베이스의 "하나의 데이터, 여러 개의 뷰" 개념을 코드 구조 자체로 구현한 부분입니다.

자주 묻는 질문은 JavaScript 없이 `<details>` 요소로 여닫습니다.
